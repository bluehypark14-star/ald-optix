01 / PROBLEM DEFINITION · 문제 정의

ALD 레시피 선정의
의사결정 문제

ALD-OPTIX는 반도체용 Al₂O₃ 박막 공정의 데이터 기반 의사결정을 지원하는 가상 B2B 소재 기업입니다. 공정 엔지니어는 고객의 목표 박막 두께와 장비 조건을 바탕으로 기존 실험자료에서 적합한 레시피 후보를 신속하게 선별해야 합니다.

기존 접근 방식 살펴보기 →
01

업무 입력

목표 두께, 온도 제한, Ar 유량, pulse·purge 조건 및 최적화 목적을 입력합니다.

02

해결 과제

제약조건을 만족하는 실측 레시피를 찾고, 성장률(GPC)과 필요한 cycle 및 이론 시퀀스 시간을 비교합니다.

03

업무 산출물

추천 후보와 계산 근거, 적용 한계, 추가 실험 필요성을 담은 공정 검토 보고서를 제공합니다. 조건을 충족하는 후보가 없으면 추천하지 않습니다.

02 / LIMITS OF EXISTING APPROACHES · 기존 접근 방식의 한계

GPC 중심 판단의
한계와 개선 방향

공개 실험자료를 수작업으로 비교하면 출처·단위·제약을 반복 확인해야 합니다. 비교를 위해 GPC만 최대화하는 단순 기준 규칙(v0)을 설정했습니다. 실제 기업의 모든 기존 업무를 대표하는 규칙은 아닙니다.

BASELINE / v0

GPC 중심 기준 방식

평균 GPC가 가장 높은 조건을 선택합니다. 성장률을 비교하기 쉽지만 온도·유량·pulse·purge 제약과 전체 시퀀스 시간을 목적함수에 반영하지 않습니다.

IMPROVED / v1

목적·제약 반영 방식

먼저 제약을 만족하는 실측 후보만 남기고, 목표 두께에 필요한 cycle과 이론 시퀀스 시간을 계산합니다. 선택한 목적에 따라 비교하고 독립 검증을 거쳐 결과를 제시합니다.

i
성장률과 시퀀스 시간은 같은 지표가 아닙니다.

GPC가 높아 cycle 수가 줄어도 purge가 길면 총 시퀀스 시간이 증가할 수 있습니다. 아래 결과에서는 동일한 10 nm 조건의 비교 사례를 확인할 수 있습니다.

03 / WHY AI & HOW · AI 활용의 필요성과 방법

AI 분석과
검증 가능한 계산의 결합

수작업 비교만으로는 여러 공정 인자와 GPC의 관계를 정량적으로 평가하거나 모델의 예측 오차를 체계적으로 비교하기 어렵습니다. 머신러닝은 데이터의 패턴을 평가하고, 공학적 계산과 제약 검증은 결과의 안전성과 재현성을 담당합니다.

01 / MACHINE LEARNING

Ridge 회귀

온도·Ar 유량·pulse·purge와 GPC의 관계를 모델링합니다. 반복 측정을 같은 그룹으로 유지하며 모델 복잡도와 예측 오차를 평가합니다.

역할: GPC 예측 모델의 내부 성능 검증
02 / ENGINEERING COMPUTATION

제약 기반 최적화

16개 실측 후보를 입력 제약으로 필터링하고 GPC·cycle·이론 시퀀스 시간을 비교합니다. ML 예측으로 미측정 레시피를 생성하지 않습니다.

역할: 결정론적 Python 계산 및 독립 검증
03 / TOOL WORKFLOW

도구 실행 자동화

구조화 요청, 고정 근거 카드 검색, 계산, 검증, 보고서 생성을 연결합니다. 선택형 LLM Function Calling은 도구 호출을 지원하며, 원래 사용자 제약을 변경할 수 없습니다.

기본: 규칙 기반 · LLM: 모의 호출 검증, 실제 API 미검증

04 / VERIFICATION & IMPROVEMENT · 결과 검증 및 개선 과정

모델의 개선 과정과
결과 검증

반복 측정값이 학습·평가에 나뉘어 유입되지 않도록, 동일 레시피의 2회 측정을 같은 그룹으로 묶어 평가했습니다.

STEP 01 / BASELINE

기준 모델 설정

학습 데이터 평균을 예측값으로 쓰는 단순 모델을 기준으로 삼았습니다. 기준 MAE는 약 0.123 Å/cycle입니다.

STEP 02 / DIAGNOSIS

복잡한 모델의 한계

교호작용을 포함한 초기 회귀의 MAE는 약 0.159 Å/cycle로 증가했습니다. 제한된 실험 데이터에서는 복잡도가 높은 모델을 그대로 채택하기 어렵다고 판단했습니다.

STEP 03 / REVALIDATION

주효과 중심 재검증

그룹 중첩 교차검증으로 모델을 선택했습니다. 외부 검증 fold 16개에서 모두 주효과 모델이 선택되었고, MAE는 약 0.090 Å/cycle였습니다.

03 / TRACEABILITY

실험 계획과 근거 관리
