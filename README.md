# ALD-OPTIX

**AI 활용 기반 ALD 공정 의사결정 지원 시스템**

가상 소재 기업을 대상으로 한 교육용 공학 프로젝트입니다. Pan & Lei (2025), *Materials* 18(9), 1918의 Tables 4–5에 공개된 Al₂O₃ thermal ALD(TMA/H₂O, Si substrate) 실측 자료(16개 DOE 조건, 32회 측정)를 활용하여 목표 두께와 공정 제약에 맞는 후보를 검색하고 검토 보고서를 생성합니다.

## 프로젝트의 문제 해결 구조

기업 홈페이지는 신소재 산업의 문제 정의부터 결과 및 기대 효과까지 다섯 단계로 구성됩니다.

| 단계 | 프로젝트 내용 |
|---|---|
| 문제 정의 | ALD 엔지니어의 목표 두께·공정 제약에 맞는 실측 후보 선정 및 검토 보고서 작성 |
| 기존 접근 방식의 한계 | GPC만 최대화하는 기준 규칙(v0)에는 제약 및 시퀀스 시간 반영이 부족함 |
| AI 활용 필요성과 방법 | Ridge 회귀로 공정 인자와 GPC의 관계 및 예측 오차를 평가하고, 계산·근거·검증 도구를 연결 |
| 검증 및 개선 과정 | 평균 기준 → 초기 복잡 회귀 → 주효과 중심 모델 선택 및 그룹 중첩 교차검증, 8개 기능 사례 비교 |
| 결과 및 기대 효과 | 내부 MAE 약 26.85% 감소, 사례 2/8 → 8/8, 10 nm 예시 시간 47.43 → 25.05분; 반복 검토 감소 및 실험 후보 선정 지원 기대 |

이 수치는 소프트웨어와 단일 문헌 데이터의 내부 평가입니다. 실제 제조 품질·업무 시간·생산비 절감은 입증되지 않았습니다. 기본 워크플로는 규칙 기반이며, 실제 LLM API 사용은 검증되지 않았습니다.

## 실행 방법

Python 3.11 권장. `app.py`가 있는 프로젝트 폴더에서 실행합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt -r requirements-dev.txt
python -m streamlit run app.py
```

자동 검증에는 Node.js가 추가로 필요합니다.

```bash
python scripts/release_check.py --strict
```

선택적으로 Playwright와 Chromium을 설치한 환경에서 `python scripts/release_check.py --browser`로 오프라인 웹 UI 검사를 실행할 수 있습니다. 설치·실행·두 웹 서비스의 연결 방법은 [RUN_GUIDE.md](RUN_GUIDE.md)를 참조하세요.

## AI 활용 및 검증 방법

- Ridge 회귀: GPC 예측 모델의 내부 성능 비교에 사용합니다. 동일한 공정 조건의 반복 측정값은 같은 그룹으로 처리합니다.
- 후보 선정: 측정된 DOE 조건을 제약조건으로 필터링하고, 선택한 결정론적 목적함수로 비교합니다. 머신러닝 예측값으로 미측정 후보를 추천하지 않습니다.
- 기본 워크플로: 입력 검증·잠금, 고정 근거 카드 검색, 공정 계산, 모델·사례 확인, 독립 검증을 순차 실행합니다. 범용 NLP나 벡터 RAG가 아닙니다.
- 선택형 LLM: 허용 도구의 Function Calling을 지원하며, 제약 변경·잘못된 응답을 검사합니다. 실시간 API 기능은 기본 비활성화되어 있으며 별도 API 키와 과금 한도가 필요합니다. [모의 호출 기록](docs/mock_llm_protocol.json)은 오프라인 테스트 자료입니다. 실제 외부 API 호출 증거는 아닙니다.
- 품질 게이트와 실행 기록 감사: 원시 CSV를 바탕으로 최적 후보·수치·보고서·도구 결과를 대조합니다. 내부 데이터 및 기록의 일관성 검사이며, 외부 API 호출의 독립 인증은 아닙니다.

## 입력 예시

구조화 입력을 권장합니다. 제한된 자연어 문법에서는 다음과 같이 수치와 단위를 명확히 지정합니다.

- `Al2O3 10nm, 최대 200°C, purge 최소 20초`
- `Al2O3 10nm, purge >= 10초, GPC 최대화`
- `Al2O3 10nm, purge < 20초`

미지원 공정 화학계, 모호한 조건 및 제외 연산자(`!=`, `≠`)는 거부합니다. 실제로 측정된 후보만 검토합니다.

## 결과 해석과 한계

기준 방식(v0)은 GPC만 최대화하는 단순 비교 규칙이며, 개선 방식(v1)은 목적과 제약을 반영합니다. 이 표기는 프로젝트 개발 버전이 아니라 비교 방법을 뜻합니다. 사전 정의 8개 사례는 소프트웨어 기능 평가이며 산업 수율을 의미하지 않습니다. 시퀀스 시간은 2 pulse 및 2 purge에 따른 이론값으로 장비 overhead와 실제 막 품질은 검증하지 않았습니다. 균형 목적의 가중치는 설계값입니다.

검사 결과와 미검증 항목은 [검증 보고서](docs/validation.md)에 구분되어 있습니다. 실제 제조 공정 승인 또는 생산성 보증을 하지 않습니다.
